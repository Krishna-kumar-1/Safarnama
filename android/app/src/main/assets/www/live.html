📄 How to configure your API keys in .env:

# 2. RailKit API Multi-Pool (Free at https://www.railkit.in/dashboard)

# 3. RapidAPI IRCTC Backup (Free at https://rapidapi.com/IRCTCAPI/api/irctc1)
RAPIDAPI_KEYS="your_rapidapi_key"
RAPIDAPI_HOST="irctc1.p.rapidapi.com"
💡 Note: The offline database of 12,466+ trains & 1,894 stations runs 100% locally even without any external API keys!
